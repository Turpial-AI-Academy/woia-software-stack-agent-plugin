# Stack assets

Reusable starting points:

- [stack-report.template.md](stack-report.template.md) — primary technology-stack decision artifact. A workflow may materialize it as `docs/project/05-STACK.md`.
- [compatibility-matrix.template.md](compatibility-matrix.template.md) — optional matrix for version/platform/interoperability relationships.

Templates are intentionally technology-neutral. Remove unused sections rather than filling them with invented detail.
